# Dear-Data-Project
Creating Coding: Dear Data 100 Assignment

This repository contains my project for this assignment. The data collected revolves around "Airbone Objects"; thus every entry is an object, of any kind, that I have seen in the world of which has been in the air. This was originally going to be restricted to celestial bodies (stars), however, I realised that data collection on these objects would be far too difficult, so I extended the type of objects I can collect data of to be any.
